### What I build

Every month, each developer sends its own reports, in its own format.
We turn them into one comparable, audited dataset — then read it.

    developer reports ──▶  Mikassa Data  ──▶  Mikassa Dashboard  ──▶  Mikassa Analyst
    (bank statements,      extract · cross-    one set of KPIs,       LLM agent on top
     ERPs, Caixa, site)    check · flag         version after version  of the whole history

**▸ Mikassa Data** — *every number, checked at the source*
Automated extraction from heterogeneous sources (bank statements, financial,
sales and construction ERPs, Caixa reports). Sources are cross-checked every
month; discrepancies are flagged at the origin, never silently fixed.

**▸ Mikassa Dashboard** — *the whole history, version after version*
The same indicators for every project: sales, construction progress,
cash flow forecast vs. actual. Compares report versions, runs our own
scenarios and produces institutional PDF reports.

**▸ Mikassa Analyst** — *an AI that knows the portfolio*
An agent grounded in certified data, crossing versions, projects and
developers to surface trends and forecasts.
